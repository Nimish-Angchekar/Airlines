# Power BI Dashboard

This project includes an interactive Power BI dashboard analyzing **5.8M airline flights from 2015**, covering flight operations, delays, cancellations, airport performance, and operational trends.

Due to the large size of the original **.pbix file**, it could not be uploaded directly to GitHub. Dashboard screenshots are included in this repository for reference.
